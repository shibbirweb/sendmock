# Acceptance: AI integration (AI)

Plan: [14-ai-integration.md](../14-ai-integration.md). Rules for IDs, ticking and tests: [README.md](README.md).

## AI-01 CLI

Phase 0 (skeleton), then every phase for its commands.

- [ ] AI-01.1 Every operation in the registry has a CLI command (parity check passes).
- [ ] AI-01.2 `--json` output is stable and documented; it is the default when stdout is not a TTY.
- [ ] AI-01.3 Exit codes are `0` ok, `1` error, `2` usage, `3` not found, `4` timeout, `5` assertion failed.
- [ ] AI-01.4 Destructive commands refuse to run without `--yes`; no command prompts unless `--interactive`.
- [ ] AI-01.5 `mss help --all --json` lists the full command tree.

## AI-02 MCP server tools

Phase 1 onwards.

- [ ] AI-02.1 `mss mcp` (stdio) and `/mcp` (streamable HTTP) expose a tool for every operation, with input schemas generated from the registry.
- [ ] AI-02.2 Tools carry correct `readOnlyHint`, `destructiveHint` and `idempotentHint` annotations.
- [ ] AI-02.3 `--toolsets` limits the exposed tools; `--read-only` hides every write tool.
- [ ] AI-02.4 Secrets are never returned by any tool.
- [ ] AI-02.5 `--embedded` starts an in-process server when none is running.

## AI-03 MCP resources and prompts

Phase 4.

- [ ] AI-03.1 Every documented resource URI returns its content; large bodies are returned as resources, not inline text.
- [ ] AI-03.2 Resource subscriptions notify on new emails, SMS and deliveries.
- [ ] AI-03.3 Every documented prompt is listed and runs its workflow.

## AI-04 Scenarios

Phase 4.

- [ ] AI-04.1 `mss scenario run` executes steps in order, saves step results for later steps and stops at the first failed `assert` with exit code `5`.
- [ ] AI-04.2 `mss scenario validate` reports errors without running anything.
- [ ] AI-04.3 The example scenarios in the skill pass in CI.

## AI-05 Agent skill and `mss ai install`

Phase 4 (skill, install), Phase 5 (plugin, evals).

- [ ] AI-05.1 `mss ai skill` outputs the skill matching the binary version.
- [ ] AI-05.2 `mss ai install --target` writes correct MCP config and instructions for Claude Code, Codex, Cursor, Gemini CLI and VS Code, shows a diff, and asks before writing.
- [ ] AI-05.3 An agent in Claude Code and in Codex completes the example session (configure app, capture OTP, set up an inbound webhook) using only the skill and tools.
- [ ] AI-05.4 Items created through CLI or MCP are tagged `created_by` and shown with a badge in the UI.

## AI-06 llms.txt

Phase 4.

- [ ] AI-06.1 `/llms.txt` and `/llms-full.txt` are served by the binary and published on the website for each version.
