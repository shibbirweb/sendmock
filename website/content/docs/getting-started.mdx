## Install

```bash
brew install sendmock
```

## Run

```bash
sendmock
```

SMTP listens on `127.0.0.1:1025` and the web UI on `http://127.0.0.1:8025`.

## Point your app at SendMock

| Stack | Setting |
| --- | --- |
| Laravel | `MAIL_HOST=127.0.0.1`, `MAIL_PORT=1025` |
| Node (Nodemailer) | `host: '127.0.0.1', port: 1025` |
| Python (smtplib) | `smtplib.SMTP('127.0.0.1', 1025)` |
