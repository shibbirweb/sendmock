MessageHook is a local sandbox for everything your app sends: email, SMS and webhooks. It runs as one small binary (or a Docker image), catches messages from any language, shows them in a web UI and calls your webhooks.

<Callout title="In development">
  MessageHook is being built in the open. The web UI is available now as a <DemoLink>live demo with sample data</DemoLink>; the server arrives with the first beta.
</Callout>

## What it does

- **Email:** a catch-all SMTP server plus SendGrid, Mailgun, Postmark, Resend, SES and Brevo compatible HTTP APIs.
- **SMS:** Twilio and Vonage compatible APIs, Twilio Verify, and simulated delivery status.
- **Webhooks:** automatic rules or manual sends, with payloads shaped like real providers.
- **AI agents:** a CLI, an MCP server and an agent skill.
